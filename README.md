# WMS Vault

Repositório colaborativo de anotações da unidade curricular **WMS**, criado para compartilhar com os colegas de classe o conteúdo registrado durante as aulas.

Como o material didático não é disponibilizado, as explicações foram construídas a partir das anotações realizadas em sala, posteriormente organizadas, revisadas e complementadas com fontes confiáveis.

## Tecnologia de anotação

Este projeto combina duas ferramentas:

- **Obsidian:** organização das notas, links entre conceitos, mapas de conteúdo e navegação pelo conhecimento.
- **Codex:** estruturação das anotações, revisão textual, pesquisa de fontes e identificação de relações entre os assuntos.

Em resumo: **Obsidian + Codex**, uma tecnologia poderosa para transformar anotações soltas em material de estudo navegável.

## Como usar no Obsidian

1. Clone ou baixe este repositório.
2. Abra o Obsidian.
3. Selecione **Abrir pasta como cofre**.
4. Escolha a pasta do repositório.
5. Abra `00 - Início.md`.

```bash
git clone https://github.com/danielsismer/wms-vault.git
```

Também é possível estudar diretamente pelo GitHub, mas o Obsidian oferece a melhor experiência para navegar pelos links internos.

## Colaboração

Correções, complementos e novas anotações são bem-vindos. Os colegas podem contribuir por meio de issues, pull requests ou compartilhando registros adicionais das aulas.

Ao contribuir:

- Preserve a organização das pastas.
- Diferencie conteúdo explicado em aula de informações complementares.
- Inclua fontes quando acrescentar dados externos.
- Não apague as notas brutas que servem como registro original.
- Mantenha o footer de autoria no final das notas.

## Aviso

Este é um material de estudo independente e não oficial. Ele não substitui orientações da professora, documentos institucionais ou materiais oficiais da WEG. Apesar do cuidado com a revisão, podem existir interpretações incompletas ou termos específicos que ainda precisem ser confirmados em aula.
